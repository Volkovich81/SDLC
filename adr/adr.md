# Выбор технологического стека для разработки CurrencyForecast

**Статус:** Принято (Accepted)
**Дата:** 2026-11-01
**Участники:** Волкович Н., Жилинский О. (Заказчик)

## Контекст и постановка задачи
В рамках лабораторных работ разрабатывается веб-приложение для прогнозирования курсов валют (CurrencyForecast). Согласно учебному заданию, основным языком разработки выбран Java. Необходимо спроектировать архитектуру, которая объединит веб-интерфейс, серверную логику и модуль машинного обучения в единую экосистему.

## Драйверы решения
* **Требование дисциплины:** весь бэкенд должен быть написан на Java.
* **Производительность:** система должна быстро обрабатывать запросы к базе данных и внешним API.
* **Интеграция ML:** необходимость внедрить алгоритмы машинного обучения без развертывания дополнительных Python-серверов.

## Рассмотренные варианты
* **Вариант 1:** Java + Spring Boot + Библиотека Smile (для ML).
* **Вариант 2:** Java + Spring Boot + Вызов внешнего Python-микросервиса по API.
* **Вариант 3:** Node.js + TensorFlow.js (отклонен, так как нарушает требование использования Java).

## Итог решения
Выбранный вариант: **Вариант 1 (Java + Spring Boot + Smile)**. Он позволяет сохранить единый язык программирования для всей серверной части, что упрощает сборку, развертывание и поддержку проекта.

### Последствия
* **Хорошо:** мы не тратим время на написание и поддержку двух разных бэкендов (Java и Python).
* **Плохо:** экосистема ML-библиотек на Java (Smile) менее обширна, чем на Python.
* **Нейтрально:** для хранения данных выбрана PostgreSQL как надежная реляционная СУБД, хорошо интегрируемая со Spring Boot.

### Подтверждение
Использование Java и Spring Boot подтверждается структурой папок. Наличие зависимостей `smile-core` и `spring-boot-starter-web` в файле конфигурации сборки будет являться автоматическим подтверждением соблюдения данного архитектурного решения при code review.

## Плюсы и минусы вариантов

### Вариант 1: Java + Spring Boot + Smile
* **Хорошо:** весь проект пишется на одном языке (Java).
* **Хорошо:** Spring Boot имеет встроенный веб-сервер, что упрощает запуск.
* **Плохо:** ML-модели на Java могут уступать по скорости обучения Python-аналогам.

### Вариант 2: Java + Python (Микросервис)
* **Хорошо:** можно использовать самые передовые ML-библиотеки Python.
* **Плохо:** требуется настраивать сетевое взаимодействие между Java и Python.
* **Плохо:** усложняется развертывание (нужно поднимать два контейнера).
