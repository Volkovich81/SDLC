\# Глоссарий проекта CurrencyForecast



| Термин | Определение |

|---|---|

| Актёр (Actor) | Роль, которую пользователь или внешняя система играет по отношению к системе |

| Прецедент (Use Case) | Последовательность действий системы в ответ на событие от актёра |

| Валютная пара | Сочетание двух валют для анализа (например, USD/BYN) |

| ML-прогноз | Прогноз будущего курса, построенный моделью машинного обучения |

| API Нацбанка | Внешний сервис с историческими данными о курсах валют |

| БД PostgreSQL | База данных для хранения курсов, истории и прогнозов |

| Дашборд | Главный экран приложения с текущими курсами |

| Поток событий | Описание основного и альтернативных сценариев прецедента |

| Предусловие | Условие, которое должно быть выполнено до начала прецедента |

| Постусловие | Условие, которое должно быть выполнено после завершения прецедента |
